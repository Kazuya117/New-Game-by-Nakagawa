# New-Game-by-Nakagawa
中川が作成した新しいゲーム

## プードルとキャッチボール 🐩🎾

ボールを投げて、黒いミディアムプードルにキャッチしてもらうブラウザゲームです。

### 遊び方

`index.html` をブラウザで開くだけで遊べます（インストール不要・スマホのタッチ操作にも対応）。

1. 画面をドラッグして**左下に引っぱり**、はなすと右上へボールを投げます（引っぱるほど強く飛びます）
2. プードルが落下地点へ走り、ジャンプしてキャッチします
3. 10球投げて合計スコアを競います。ベストスコアはブラウザに保存されます

### iPhone / スマホで遊ぶ

- 公開URLを Safari などで開くだけで遊べます。**横向き**にすると大きな画面になります
- Safari の共有ボタン →「ホーム画面に追加」で、アプリのように全画面で起動できます
- 音は消音スイッチ（マナーモード）がオンでも鳴ります（iOS 16.4 以降）。消したいときは画面右上の 🔊 ボタンを押してください
- それでも音が出ないときは、本体の音量と、古い iOS の場合は消音スイッチを確認してください

### スコア

| 内容 | 点数 |
| --- | --- |
| ノーバウンドキャッチ | 距離(m) × 2 |
| バウンド後のキャッチ | 距離(m) × 1 |
| ダイビングキャッチ（ギリギリ届いた） | +10 |
| ★ボーナスゾーンの上でノーバウンドキャッチ | +30 |
| ノーバウンドの連続キャッチ | +5 × (連続数 − 1) |
| 画面の外まで飛んでしまった | 0 |

### コツ

- プードルの足の速さには限界があります。遠くへ投げるときは**高い山なり**にして、走る時間を作ってあげましょう
- 3球目から風が吹きます。右上の風向きを見て投げる強さを調整しましょう

### ファイル構成

- `index.html` … ページ本体
- `game.js` … ゲームのロジックと描画（Canvas、外部ライブラリなし）
